It still looks like Garamond

	
Most coding fonts are drawn with one even line. These letters come from a type cut for books, so they keep their bowls, their tapered strokes and their small x-height, even at one fixed width.

Nothing to mistake

			
The zero has a dot, and the i, l and 1 each have their own shape. The stylistic set ss01 swaps in a plain zero.

		

		

			
1534 1534

			
Two sets of figures

			
Lining figures for code, and old-style figures for prose and comments, through the onum feature.

		

		

			
→ ⇒ ↩

			
Arrows with a pen behind them

			
Hairline shafts and swept heads, built from Garamond's own arrows rather than bolted on.

		

	






	
A true italic for your comments

	
Not the roman on a slant. The italic has its own cursive letters and a swash ampersand, so a comment reads like a note in the margin. Operators and arrows stay upright, so they still line up with the code around them.

Ligatures that respect the grid

	
More than 150 sequences join up as you type, and all of them are built from the font's own glyphs. A ligature takes exactly the cells of the characters it replaces, so nothing shifts and your cursor still lands on each one.

Install

	
Download the fonts, unzip them and install the six fonts in the ttf folder, then point your editor at it. It's free, under the SIL Open Font License.

	

		
VS Code
"editor.fontFamily": "Garamonto Code",
"editor.fontLigatures": true,
"editor.fontSize": 15

		
Ghostty
font-family = Garamonto Code
font-size = 15

		
kitty
font_family Garamonto Code
font_size 15

		
On the web
@font-face {
  font-family: "Garamonto Code";
  src: url("GaramontoCode.woff2") format("woff2");
}
code { font-family: "Garamonto Code"; }

	

	
Garamond's small x-height makes it look a size smaller than most coding fonts, so start a point or two above your usual size. On dark themes, try Medium.
